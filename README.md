# 🏏 Cricket LLM

A multi-tool **Cricket AI Assistant** built with **LLMs, RAG, ML, and DL models**. This project combines advanced AI techniques with structured cricket data to enable match predictions, score forecasting, and contextual cricket Q&A.

---

## 🚀 Features

* **Match Winner Prediction** – Achieved **92% accuracy** using Random Forest.
* **Score Prediction** – Deep Learning model with **14 MSE**.
* **Cricket Q&A Chatbot** – Built with **LLaMA + Pinecone (RAG)** for contextual insights.
* **Structured Stats Retrieval** – SQL tool powered by Gemma with **85% query execution accuracy**.
* **MERN-based Dashboard** – Intuitive UI to interact with cricket stats and predictions.

---

## 🛠️ Tech Stack

* **LLMs & NLP:** LLaMA, LangChain, Pinecone, Gemma
* **ML/DL:** Random Forest, Deep Learning (Keras/TensorFlow)
* **Backend:** Node.js, Express.js, FastAPI
* **Frontend:** React.js (MERN)
* **Database:** MongoDB, MySQL

## ⚡ Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/varshithkumar7779/cricket-LLM.git
cd cricket-LLM
```

### 2️⃣ Install Dependencies

Frontend (React):

```bash
cd frontend
npm install
npm start
```

Backend (Express + FastAPI):

```bash
cd backend
npm install
python -m venv venv
source venv/bin/activate  # (Linux/Mac) OR venv\Scripts\activate (Windows)
pip install -r requirements.txt
```

### 3️⃣ Run the App

* Start backend servers (Express + FastAPI)
* Start frontend React app
* Access at `http://localhost:3000/`
